# KeyTitan

A simple, cross-platform password manager using flutter and dart. Portable for desktop and android. The original version(originally called Hydra), writting in Python, can be found here: https://github.com/chaosandcarbs/hydra. Password files are not currently backward compatible.

KeyTitan can create, read, and edit encrypted (using Salsa20) password file containers on disk. Cloud integration is with Google, and uses Google OAuth to authenticate with your Drive account.
